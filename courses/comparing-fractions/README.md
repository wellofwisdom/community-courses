# Comparing Fractions

A short example course, and a template for contributors. Two lessons: comparing fractions that share a denominator, then fractions that do not, finished with a number line you build by hand.

- **Topic:** Comparing fractions with the same and different denominators
- **Grade:** 4
- **Lens:** none
- **License:** CC-BY-4.0
- **Units:** 1  **Lessons:** 2  **Items:** 8
